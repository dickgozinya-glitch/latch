# Latch — one page for a controller

**What**  
A gate in front of agent spend. Allow, deny, or escalate. Then a signed Seal.

**What it is not**  
Not a wallet. Not an agent. Not a card network.

**Who pays**  
The firm whose agents spend. Finance or security.

**Price to start**  
$3,000 / month floor against $0.05 per decision. Setup $5–15k to sit on one existing pipe (cloud, ads, vendor card, contractor payout).

**Why you cannot build this inside the model vendor**  
The factory cannot independently attest its own agents. Banks and insurers will eventually require a seal they did not issue.

**Install**  
`python3 server.py`  
Then one POST before the charge.

**Ask**  
Name the exact API call that moves money. We sit in front of it. Invoice the same week the first decision fires.
